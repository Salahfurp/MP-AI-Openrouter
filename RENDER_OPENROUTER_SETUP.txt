MASTER PLAN AI ASSISTANT - OPENROUTER SETUP

1) Upload/replace ALL files in this ZIP to the GitHub repository.
2) In Render > your Web Service > Environment, add:
   OPENROUTER_API_KEY = your OpenRouter API key
3) Keep OPENROUTER_MODEL = openrouter/free (optional; the app defaults to it).
4) Save changes. Render should redeploy automatically.
5) Open the Render app URL and ask questions in Arabic or English.

IMPORTANT:
- Never put the API key inside GitHub files.
- The app uses local BM25 retrieval over guide_pages.txt and OpenRouter only to understand the query and answer from retrieved UPPG excerpts.
