Master Plan AI Assistant - V7

Key fixes:
1) UPPG retrieval no longer calls AI to create the search query. This prevents reasoning/thinking text from corrupting BM25 retrieval.
2) Search expansion/internal reasoning is never shown to the user. Only retrieved UPPG evidence pages are shown.
3) Deterministic routing separates:
   - UPPG Q&A
   - Public Facilities calculation
   - Public Facilities deficit/compliance review
4) Deficit review remains a persistent workflow and continues automatically after project area + population are collected.
5) Excel/PDF/CSV/TXT attachments stay inside the chat workflow.
6) Arabic/English facility matching uses aliases + fuzzy matching + AI semantic fallback for ambiguous names.
7) Once a service level is activated, all mandatory services in that level are included.
8) Gemini 3.8 Flash requests use low thinking by default for real-time chat. Override with GOOGLE_THINKING_LEVEL if required.
